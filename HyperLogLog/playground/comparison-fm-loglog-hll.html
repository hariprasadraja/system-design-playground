Comparative study · all three

FM vs LogLog vs HyperLogLog

Same hashes, same customer counts. Three estimators, one question: how close is each to the true distinct count? Errors and performance compared.

SECTION 1 · THE THREE ESTIMATORS

Side by side

Flajolet–Martin (FM)

Bitmap: first empty rank R → estimate = 2^R / φ
φ ≈ 0.77351   (Theorem 3.A product)

LogLog

Registers: bucket = top(log2 m) bits → max rank
estimate = α · m · 2^(mean register)
α ≈ 0.39701

HyperLogLog (HLL)

Registers: bucket = top(log2 m) bits → max rank
estimate = α_m · m² / Σ 2^(−R_j)
α_m ≈ 0.709 for m = 64; linear counting for small n

The truth

estimate error = |estimate − actual n| / actual n
