EXPERIMENT 03 · VARIANCE, BIAS & STANDARD ERROR · pp. 195–203

    
Same customers. Many imaginary hash assignments.

    
One answer cannot measure accuracy. Here each trial gives the same n distinct customers a new set of pseudorandom 32-bit tickets. Within a trial each ID has one ticket; repeat receipts would reuse it and add no evidence. This samples the paper's uniform-hash model, rather than running the receipt hash.

    

      
      
      
      
      
    

    
Try m=16, then 64, then 256 with the same n. Four times the notebooks should roughly halve standard error. Then try n=12, m=64: small-population bias breaks this rule of thumb.

    

    
MeasurementSample across trialsLarge-load theory / meaning

    
Where did PCSA estimates land?

    
Sample variance divides by trials−1. Standard error here means SD(estimate)/true n, as in the paper, not SD/√trials. The bias correction rescales estimates by 1/(1+0.31/m); it does not repair the startup regime. No hard ±10% guarantee.

  


  

    
EXPERIMENT 04 · THE DISTRIBUTION OF R · pp. 186–191

    
Where is the first missing rank likely to be?

    
This is a distribution over R after n distinct customers, not over one customer's ρ. We compute Theorem 1 with inclusion–exclusion, then compare equation (14)'s ψ approximation and sampled frequencies.

    

    
q[n,k] = P(R ≥ k)       p[n,k] = q[n,k] − q[n,k+1]
q[n,2] = 1 − (1/2)^n − (3/4)^n + (1/4)^n
ψ(x) = (1−e^−x)(1−e^−2x)(1−e^−4x)…
p[n,k] ≈ ψ(n/2^k) − ψ(n/2^(k+1))

What happened to Table I in the PDF?
The printed table calls the values q, but its bell-shaped entries behave like p. Its displayed ranks and exact/approximate rows also appear inconsistent with the zero-based equations. For n=100 and k=6 the equations give exact p≈0.34757612 and ψ approximation≈0.34529782. This lab recomputes the equations rather than copying the table. Exact here means the exact formula evaluated with finite-precision arithmetic; very small tails can suffer cancellation.

    
Work the two-customer variance by hand
R=0,1,2 has probabilities 1/4,1/2,1/4. Mean=1. Squared distances from 1 are 1,0,1. Their weighted average is 0.5: the variance. SD=√0.5≈0.7071 ranks. For large n, SD(R) is about 1.12127 ranks, not 1.12127 customers.

  


  

    
EXPERIMENT 05 · THEOREM 3.A · pp. 193–195

    
The “magic” constant is a computable product.

    
The probability analysis finds E[R]≈log₂n−0.3704964. φ converts this systematic rank offset into a scale correction. It is derived from the model, not fitted to our store.

    
φ = e^γ / √2 × (2/3) × ∏ [((4j+1)(4j+2)) / ((4j)(4j+3))]^((-1)^popcount(j))
γ = 0.5772156649015329     j = 1, 2, 3, …
Even popcount: multiply. Odd popcount: divide.

    

    

    
The derivation bridge
Exact distribution → expected rank → Mellin transform over powers-of-two scales → constant offset (γ+N′(0))/ln(2)−1/2 → ln φ = γ+N′(0)−ln(2)/2 → this product. See lesson §8 for the intermediate expressions.
Average before exponentiating
Two notebook readings: R=2 and R=4.
2^average(2,4) = 8
average(2^2,2^4) = 10
Calibrating E[R] does not make 2^R/φ unbiased. PCSA's residual bias ratio is roughly 1+0.31/m.

    
The tiny periodic effect and the appendix
Doubling n moves the binary ruler about one whole rank. A tiny ripple repeats in the fractional part of log₂n. Theorem 3.A bounds its amplitude by 10⁻⁵ rank units; the appendix controls Fourier coefficients using the Gamma function and N(s). This is distinct from ordinary trial-to-trial noise. The product uses the Thue–Morse sign sequence, discussed in the note added in proof.

  


  

    
EXPERIMENT 06 · MERGING, DELETIONS & SCROLLING · pp. 204–205

    
Two checkouts, the same store

    
The 20-receipt log includes customers who use both checkouts. OR corresponding bitmap cells to form the union. The result must match processing all receipts centrally, bit for bit.

    
Same hash + seed + m + width on both checkouts.

    

      
Delete one receipt safely
Two customers share rank 0. Track active receipt occurrences. A bit remains 1 while at least one contributing receipt remains.

      
Reconstruct the paper's fringe
All rows begin with four ones, followed by a mixed fringe and trailing zeros. Store a boundary and the fringe instead.
Boundary = 4

This example is exactly reconstructible because its omitted cells are known. A fixed-width scrolling implementation needs a policy for rare out-of-window bits. Scrolling ranks is not expiring old receipts.

    

  

  

    
What to remember

    
Bitmap → first missing rank → average ranks → exponentiate → calibrate. PCSA adds stable hash partitioning and a factor of m.

    
Small n/m, biased hashes, finite bitmap widths, hash collisions, incompatible merges and basic-bit deletions are real limitations. These experiments expose several of them. The full lesson covers the limits, proof outline, all five theorems, empirical tables and remaining paper details.
